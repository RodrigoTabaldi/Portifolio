# Vitrine Software

Landing page institucional construída com React, TypeScript e Vite.

## Requisitos

Node.js 22.13 ou superior.

## Desenvolvimento

```sh
npm install
npm run dev
```

Abra `http://127.0.0.1:3000`.

## Produção

```sh
npm run build
npm run start
```

O build é gerado na pasta `dist/`.
