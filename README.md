# Rodrigo Tabaldi — Portfólio

Portfólio de Rodrigo Tabaldi com Next.js, React e TypeScript. Identidade azul inspirada na hierarquia visual do site da Docker; mídia e copy próprias. Foto real, stacks, perfil, contatos e seis projetos com filtros e detalhes técnicos.

## Executar no PowerShell

```powershell
Set-Location C:\Users\rodri\source\repos\reactproject1
npm.cmd install
npm.cmd run dev
```

Abra http://localhost:3000. Não requer banco ou chave de API.

## Verificação e produção

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
npm.cmd start
```

## Conteúdo

- `src/data/projects.ts`: seis projetos e links.
- `src/app/page.tsx`: apresentação, stacks e contato.
- `src/app/globals.css`: aparência e responsividade.
- `public/images`: foto e imagens originais do GitHub.
- `docs/references`: perfil e READMEs consultados em 01/10/2026.
- `docs/design`: conceitos visuais gerados como referência.

Triar, Vistora, Voytek e Atlas usam capturas reais. Kronos usa sua marca e FASTcare uma ilustração original, identificadas nos cartões. Conteúdo estático, sem atualização automática do GitHub. Fontes locais. Contatos incluem e-mail, LinkedIn e GitHub. Respeita movimento reduzido. Site não publicado.
